# 💪 나의 식단·운동 기록

오늘 먹은 음식과 운동(종류, 세트별 중량·횟수, 시간)을 기록하는 개인용 웹앱. 어두운 톤 화면이 기본이고, 헤더의 🌙 버튼으로 밝은 테마로 바꿀 수 있습니다.

## 🏋️ 운동
- **세트별 중량·횟수** 기록표, 완료 체크, 세트 단위 추가/삭제
- **1RM 추정** — `100kg×1`보다 `90kg×8`(1RM 114)이 더 센 기록이라는 걸 알려줍니다. 최고 기록과 추이 그래프 모두 1RM 기준
- **운동 시간** — 시작/끝내기 버튼으로 자동 측정
- **부위별 밸런스** — 가슴만 하고 등을 빼먹고 있으면 알려줍니다
- **꾸준함** — 연속 운동 일수와 주 N회 목표

## 🍚 식단
- **사진 첨부** — 먹은 걸 찍어두면 목록에 함께 남습니다. 평소 동기화에는 안 들어가고(너무 무거워서), 옮길 땐 `📷 사진까지 내보내기`로 받은 파일을 다른 기기에서 가져오면 됩니다
- **단백질 추적** — 음식만 적으면 칼로리와 함께 자동 계산, 목표는 체중 × 1.6g
- **물 섭취** — 탭 한 번으로 한 잔

## 🏋️ 세트별 중량·횟수 기록
운동마다 세트 표가 있어서 세트별로 중량(kg)과 횟수를 따로 적을 수 있습니다.

- 세트 번호를 누르면 완료 체크, ✕로 그 세트만 삭제, `+ 세트 추가`로 한 세트씩 추가
- **완료 체크한 세트만** 볼륨과 소모 칼로리에 들어갑니다. 미리 계획만 넣어둔 세트는 집계되지 않아요. (체크를 하나도 안 하면 전체를 집계합니다)
- 운동마다 **전체 기간 최고 기록(PR)** 과 세운 날짜가 표시되고, 기록을 깨면 `🎉 신기록!`이 뜹니다

## 🍚 식단
- **사진 첨부** — 먹은 걸 찍어두면 목록에 함께 남습니다. 평소 동기화에는 안 들어가고(너무 무거워서), 옮길 땐 `📷 사진까지 내보내기`로 받은 파일을 다른 기기에서 가져오면 됩니다 칼로리 자동 계산
음식 이름과 양을 적으면 칼로리가 자동으로 채워집니다.

- 양은 `200g` `1공기` `2개` `1봉지` `1잔` 처럼 숫자 + 단위로 적으면 됩니다
- 예) 밥 1공기 → 300 kcal, 라면 1봉지 → 505 kcal, 닭가슴살 200g → 218 kcal
- 양을 안 적으면 1인분 기준으로 추정합니다
- 표에 없는 음식이거나 값이 다르면 칼로리를 직접 적으면 되고, 직접 적은 값은 자동으로 덮어쓰지 않습니다
- 음식을 더 넣고 싶으면 `food-db.js`에 추가하세요

## 🔥 소모 칼로리 자동 계산
운동 탭에 체중을 한 번 적어두면, 운동을 추가할 때마다 소모 칼로리가 자동으로 계산됩니다.

- 계산식: `MET × 체중(kg) × 운동 시간(h)`
- MET(운동 강도)는 운동 이름으로 자동 추정합니다. (러닝 8.0, 스쿼트 6.0, 벤치프레스 5.0, 걷기 3.5 …)
- 기구 이름을 통째로 외우는 게 아니라 `프레스` `로우` `케이블` 같은 **공통 단어**를 잡기 때문에, 랫풀다운·컨버징체스트프레스·핵스쿼트처럼 목록에 없는 기구도 대부분 알아봅니다. 못 찾으면 기본 5.0(일반 웨이트)입니다.
- **값이 안 맞으면 운동 카드의 MET 칸에서 직접 고칠 수 있습니다.** 고친 값은 같은 이름의 운동에 날짜 상관없이 모두 적용되고, `↺ 자동` 을 누르면 원래 추정값으로 돌아갑니다.
- 운동 시간을 안 적으면 **세트당 3분**으로 추정하고 `(추정)` 이라고 표시합니다.
- 식단·기록 탭에서는 `섭취 − 소모 = 순 칼로리`도 같이 보여줍니다.

어디까지나 추정치라서 실제 소모량과는 차이가 있을 수 있습니다.

## 그 밖에 편한 것들
- **지난번 기록** — 운동 이름을 치면 지난번에 몇 kg 몇 회 했는지 바로 보여줍니다
- **루틴 불러오기** — `↩ 09/21 운동 3종 그대로 불러오기` 버튼 하나로 복사 (식단도 됩니다)
- **± 버튼** — 중량·횟수를 타이핑 없이 조절. 중량 단위는 설정에서 바꿀 수 있어요 (기본 2.5kg)
- **휴식 타이머** — 세트 완료를 누르면 자동 시작, 끝나면 진동 + 알림음
- **자주 먹는 음식** — 많이 먹은 음식을 칩으로 띄워 한 번에 추가
- **목표 칼로리** — `목표 + 소모 − 섭취 = 남은 칼로리`
- **통계 그래프** — 기록 탭에서 7/30/90일을 골라 섭취·소모, 체중 추이, 운동별 중량 추이를 봅니다
- **체중 기록** — 날짜별로 적어두면 추이가 그려지고, 과거 소모 칼로리도 그때 체중으로 계산됩니다
- **운동 순서 바꾸기** — 카드의 ↑↓ 버튼
- **검색 / 월별 접기** — 기록이 쌓여도 원하는 날을 금방 찾습니다
- **되돌리기** — 잘못 지워도 7초 안에 복구
- **날짜 이동** — 좌우 스와이프, `오늘` 버튼
- **메모** — 컨디션·통증 같은 걸 날짜별로 적어둘 수 있어요

## 🔄 다른 기기와 동기화
기록 탭 아래쪽에 있습니다. **어느 방법이든 합칠 때 기록이 사라지지 않습니다** — 같은 날에 PC에서 점심을, 휴대폰에서 저녁을 적었어도 둘 다 남고, 한쪽에서 지운 건 다른 쪽에서도 지워집니다.

### 💻 PC — 파일 자동 저장 (토큰 없음, 권장)
`파일 지정`을 눌러 **OneDrive·구글드라이브 폴더**에 파일을 한 번 잡아두면 끝입니다. 이후 기록할 때마다 자동 저장되고, 다른 PC에서 같은 파일을 지정하면 합쳐집니다. 크롬·엣지에서 동작합니다.

### 📱 휴대폰 (토큰 없음)
휴대폰 브라우저는 자동 저장을 지원하지 않아 한 단계가 수동입니다.

1. 휴대폰에서 `내보내 공유` → 드라이브 앱에 저장 (공유가 안 되는 기기는 `내보내기`)
2. PC나 다른 기기에서 `가져오기` → 그 파일 선택 → 합쳐짐

### ⚙️ GitHub Gist (토큰 필요)
휴대폰까지 **자동으로** 맞추고 싶을 때만 쓰세요. GitHub 개인 토큰(`gist` 권한만)을 브라우저에 저장해야 해서 기본에서 내려 뒀습니다. 토큰은 이 기기에만 저장되고 백업 파일에는 들어가지 않으며, `연결 해제`로 지울 수 있습니다. 공용 PC에서는 쓰지 마세요.

1. 휴대폰 브라우저로 위 주소 접속
2. **안드로이드(크롬)**: 기록 탭의 `📲 홈 화면에 앱으로 설치하기` 버튼, 또는 메뉴 → 앱 설치
3. **아이폰(사파리)**: 공유 버튼 → 홈 화면에 추가

설치하면 주소창 없이 앱처럼 열리고, 오프라인에서도 동작합니다.
